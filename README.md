# Jenny Kliushnik — UX-designer · Portfolio

Personlig portfolio för Jenny Kliushnik, UX-designstudent på Nackademin i Stockholm.
Söker LIA i Stockholm, november 2026 – april 2027.

🔗 Live: https://jennykliushnik.netlify.app

## Innehåll

- **Startsida** (`index.html`) — om mig, projekt, omdömen, kompetens, bakgrund och kontakt
- **Case** — Titra Health, Freshly, The Viking Museum, Meter, TV4 Play och Wingspan (`case-*.html`)
- **Freshly** — designsystem (`freshly-designsystem.html`) och mockups (`freshly-mockups.html`, `.pdf`)
- **Engelsk version** — samma sidor i mappen `en/`
- **CV** — på svenska och engelska (`Jenny_Kliushnik_CV.pdf`, `Jenny_Kliushnik_CV_EN.pdf`)
- **Bilder** — i mappen `bilder/` (WebP)

## Teknik

Ren HTML och CSS, med lite vanilla JavaScript. Inga ramverk och inget byggsteg — öppna `index.html` i en webbläsare, eller publicera mappen som den är (t.ex. på Netlify eller GitHub Pages).

## Tillgänglighet

- Kontrast enligt WCAG AAA för brödtext, i både ljust och mörkt läge
- Fungerar med tangentbord och skärmläsare: skip-länk, synligt fokus, beskrivande alt-texter och etiketter
- Respekterar inställningen *minskad rörelse* (`prefers-reduced-motion`)
- Mörkt läge följer systemets inställning och kan växlas manuellt
- Svensk och engelsk version med `hreflang`

## Publicering

Netlify: dra mappen till https://app.netlify.com/drop, eller koppla repot och sätt *publish directory* till roten.
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
